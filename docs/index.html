Face Screen Lock

Automatically locks your screen when you step away — powered by real-time facial recognition, fully local with no cloud dependency.

Python 3.9+ OpenCV LBPH Windows macOS Linux EN / فارسی
What it does

Features

🎯

Real-Time Face Recognition

Captures a frame every few seconds and recognizes your face using OpenCV's LBPH algorithm — lightweight, local, and fast.

🧠

Adaptive Learning

Automatically updates your model when high-confidence matches are detected. Adapts to gradual appearance changes like new glasses or a beard — no re-enrollment needed.

⌨️

Activity Awareness

Won't lock while you're actively typing or moving the mouse. Cross-platform idle detection with a configurable grace period and security ceiling.

👤

Stranger Detection

If a face is detected but doesn't match you, the system locks faster — and keyboard activity won't delay the lock.

📹

Meeting Mode

Detects running meeting apps (Zoom, Teams, Skype, Webex…) and multiplies the lock timeout, so natural gaze shifts during calls don't trigger locks.

🌐

Bilingual UI

Full Persian (فارسی) and English support across the menu, settings window, and logs. Switch languages live — no restart needed.

🖥️

System Tray Icon

Colored circle in the menu bar or system tray shows your live detection status at a glance — no terminal needed during daily use.

☁️

100% Local

Face images, trained model, and logs never leave your machine. No accounts, no subscriptions, no cloud calls.

Under the hood

How It Works

1

Enrollment (one-time setup)

The guided wizard captures ~40 face samples across different angles and lighting conditions, then trains an LBPH model saved to data/model.yml.

2

Continuous Monitoring

Every check_interval_seconds (default: 2s), the monitor captures a frame, runs Haar Cascade face detection, and passes detected faces to the LBPH model for recognition.

3

Decision Logic

Owner recognized → reset away-timer. No face or stranger detected → increment away-timer. Activity override, meeting mode, and stranger detection all modify the final lock decision.

4

Screen Lock

When away-time exceeds the threshold, the OS-specific lock command runs: LockWorkStation() on Windows, pmset displaysleepnow on macOS, loginctl lock-session on Linux.

5

Adaptive Retrain (background)

When a high-confidence recognition occurs (above adaptive_learning_confidence_threshold), the frame is saved and the model silently retrains — keeping up with gradual appearance changes.

Getting started

Installation & Quick Start

Step 1 — Install dependencies

pip install -r requirements.txt
⚠️

Do not use Apple's system Python — it ships with Tcl/Tk 8.5 which crashes the settings window. Install a modern Python via Homebrew:

brew install python@3.12 python-tk@3.12
pip install -r requirements.txt
pip install -r requirements.txt

# If tkinter is missing (Debian/Ubuntu):
sudo apt install python3-tk

Step 2 — Enroll your face (once)

python enroll.py
./enroll.sh
💡

The wizard guides you through 6 angles (forward, left, right, up, down, low-light). After all steps the model trains automatically and saves to data/model.yml.


Step 3 — Start monitoring

# System tray icon (recommended)
python menubar.py

# Headless — no icon
python monitor.py

# With live camera preview for tuning
python monitor.py --debug
./run.sh             # System tray icon (recommended)
./monitor.sh         # Headless — no icon
./monitor.sh --debug # With live camera preview
⚠️

macOS only: Go to System Settings → Lock Screen and set "Require password after screen saver begins or display is turned off" to Immediately — otherwise the screen turns off but nothing actually locks.

Run at boot

Auto-Start at Login

Create a shortcut and drop it in the Startup folder:

Win+R → shell:startup

Create a shortcut with:
Target:   C:\path\face-screen-lock\menubar.py
Start in: C:\path\face-screen-lock

Or use Task Scheduler → Create Task → Trigger: At log on → Action: python menubar.py

Create a LaunchAgent plist:

# ~/Library/LaunchAgents/com.nima.facelock.plist

<?xml version="1.0" encoding="UTF-8"?>
<plist version="1.0">
<dict>
  <key>Label</key>
  <string>com.nima.facelock</string>
  <key>ProgramArguments</key>
  <array>
    <string>/full/path/to/run.sh</string>
  </array>
  <key>RunAtLoad</key> <true/>
  <key>KeepAlive</key>  <true/>
</dict>
</plist>

# Load it:
launchctl load ~/Library/LaunchAgents/com.nima.facelock.plist

Create a systemd user service:

# ~/.config/systemd/user/facelock.service

[Unit]
Description=Face Lock Monitor

[Service]
ExecStart=/full/path/to/run.sh
Restart=on-failure
Environment=DISPLAY=:0

[Install]
WantedBy=default.target
systemctl --user daemon-reload
systemctl --user enable --now facelock.service

Good to know

Limitations

💡

LBPH — not deep learning

Good for personal/office use. Degrades in very low light or extreme angles. Not a replacement for Windows Hello or Touch ID.

📷

Shared webcam

If Zoom or Teams uses the same camera, frame capture fails silently — the app logs the error and does not lock (safe but unmonitored).

🌐

Browser meetings undetectable

Google Meet in Chrome shows as just "Chrome running" — only standalone meeting apps (Zoom, Teams…) can be detected by process name.

🍎

macOS needs a setting

pmset displaysleepnow only turns the display off. You must enable "Require password immediately" in System Settings for it to actually lock.
