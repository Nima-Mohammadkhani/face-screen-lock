Documentation

Face Screen Lock

Automatically locks your screen when you step away — powered by real-time facial recognition. Runs entirely on your machine, no cloud, no accounts.

Python 3.9+ OpenCV LBPH Windows macOS Linux EN / فارسی
Capabilities

Features

🎯

Real-Time Face Recognition

Captures a frame every few seconds and recognizes you via OpenCV's LBPH algorithm — lightweight, fast, fully offline.

🧠

Adaptive Learning

Auto-updates your model on high-confidence detections. Adapts to gradual changes (glasses, beard, lighting) without re-enrollment.

⌨️

Activity Awareness

Won't lock while you're actively typing or moving the mouse. Configurable grace period with a security ceiling to prevent bypass.

👤

Stranger Detection

Detects faces that don't match you and switches to a shorter lock timeout — overriding any activity-based delay.

📹

Meeting Mode

Detects running meeting apps (Zoom, Teams, Skype…) and multiplies the lock timeout so gaze shifts during calls don't trigger locks.

🌐

Bilingual UI

Full Persian (فارسی) and English support — menu, settings window, and logs. Switch languages live without restarting.

🖥️

System Tray Icon

A colored circle in the menu bar or system tray shows live detection status. Click for the status menu and settings.

☁️

100% Local

Face images, trained model, and logs never leave your machine. No accounts, no subscriptions, no internet required.

Under the hood

How It Works

1

One-time enrollment

The guided wizard captures ~40 face samples across 6 angles and lighting conditions, then trains an LBPH model saved to data/model.yml.

2

Continuous frame capture

Every check_interval_seconds (default 2s), the monitor grabs a webcam frame and runs Haar Cascade face detection on it.

3

Recognition & decision logic

Detected faces are compared against your LBPH model. Activity override, meeting mode, and stranger detection each modify whether and how fast the screen locks.

4

OS-native screen lock

When the away-timer exceeds the threshold, the OS lock command fires: LockWorkStation() on Windows · pmset displaysleepnow on macOS · loginctl lock-session on Linux.

5

Background adaptive retrain

High-confidence recognitions save a new sample and silently retrain the model, keeping it aligned with gradual appearance changes over time.

Getting started

Installation

Python 3.9 or higher is required. Install all dependencies with a single command:

pip install -r requirements.txt
⚠️

Do not use Apple's system Python. It ships with Tcl/Tk 8.5 which crashes the settings window. Use Homebrew:

brew install python@3.12 python-tk@3.12
pip install -r requirements.txt
pip install -r requirements.txt

# If tkinter is missing (Debian / Ubuntu):
sudo apt install python3-tk
One-time setup

Face Enrollment

Run the enrollment wizard once before starting the monitor. It captures samples from multiple angles and trains your personal model.

python enroll.py
./enroll.sh
ℹ️

The wizard guides you through 6 angles: forward, left, right, up, down, and optional low-light. The model saves automatically to data/model.yml when done.

Running the app

Start Monitoring

python menubar.py           # system tray icon (recommended)
python monitor.py           # headless, no icon
python monitor.py --debug   # live camera preview for tuning
./run.sh              # system tray icon (recommended)
./monitor.sh          # headless, no icon
./monitor.sh --debug  # live camera preview for tuning
⚠️

macOS only: Go to System Settings → Lock Screen and set "Require password after screen saver begins or display is turned off" to Immediately. Without this, the screen turns off but nothing actually locks.

ℹ️

Linux (GNOME): If the system tray icon doesn't appear, install the AppIndicator/KStatusNotifierItem extension, or use monitor.py directly.

Boot time

Auto-Start at Login

Place a shortcut in the Startup folder (Win+R → shell:startup):

Shortcut target:  python "C:\path\face-screen-lock\menubar.py"
Start in:         C:\path\face-screen-lock

Or use Task Scheduler → Create Task → Trigger: At log on → Action: python menubar.py

Create ~/Library/LaunchAgents/com.nima.facelock.plist:

<?xml version="1.0" encoding="UTF-8"?>
<plist version="1.0">
<dict>
  <key>Label</key>
  <string>com.nima.facelock</string>
  <key>ProgramArguments</key>
  <array><string>/full/path/to/run.sh</string></array>
  <key>RunAtLoad</key><true/>
  <key>KeepAlive</key><true/>
</dict></plist>
launchctl load ~/Library/LaunchAgents/com.nima.facelock.plist

Create ~/.config/systemd/user/facelock.service:

[Unit]
Description=Face Lock Monitor

[Service]
ExecStart=/full/path/to/run.sh
Restart=on-failure
Environment=DISPLAY=:0

[Install]
WantedBy=default.target
systemctl --user daemon-reload
systemctl --user enable --now facelock.service

Limitations

💡

LBPH, not deep learning

Good for personal use. Degrades in very low light or extreme angles. Not a replacement for Windows Hello or Touch ID.

📷

Shared webcam

If Zoom or Teams uses the same camera, frame capture fails silently — the app logs the error and does not lock (safe, but unmonitored).

🌐

Browser meetings

Google Meet in Chrome only appears as "Chrome running" — only standalone apps (Zoom, Teams…) can be detected by process name.

🍎

macOS display sleep

pmset displaysleepnow only turns the display off. "Require password immediately" must be enabled in System Settings to actually lock.
